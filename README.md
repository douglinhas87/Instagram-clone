Projeto Front-End desenvolvido com Angular 17, inspirado na interface do Instagram, com funcionalidades básicas de feed, perfil e navegação.

---

## 🚀 Funcionalidades

- Feed com posts (imagem, curtidas, avatar)
- Página de perfil do usuário (em construção 🛠️)
- Barra lateral com navegação e ícones reais do Instagram
- Estrutura com Angular Standalone Components

---

## 🛠️ Tecnologias utilizadas

- Angular 17 (Standalone Components)
- TypeScript
- Lucide Icons (ícones SVG inspirados no estilo Instagram)
- HTML + CSS
- (Em breve) Responsividade com CSS Grid/Flexbox

---

Projeto criado para prática e também para compor o meu portfólio como Front-End Developer. Próximos passos:

- Implementar responsividade completa

## 📦 Como rodar o projeto

Clone o repositório:

```bash
git clone https://github.com/douglinhas87/clone-instagram.git
```
Instale as dependências:

```bash
npm install
```

Rode a aplicação:

```bash
ng serve
```

Acesse em: http://localhost:4200
